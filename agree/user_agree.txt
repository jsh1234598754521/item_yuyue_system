物品预约系统用户协议
一、协议主体与适用范围
1. 本协议为北附学校物品预约系统（下称 “本系统”）使用用户与系统管理方（学校后勤 / 器材管理处）之间的有效服务约定，凡注册、登录、使用本系统进行器材预约、借用、归还、查询、反馈等全部操作，即代表您已完整阅读、充分理解并自愿同意本协议全部条款。
2. 本系统仅限本校在校师生、在职教职工实名使用，校外人员未经管理员许可不得注册、登录及使用系统。
二、账号注册与信息规范
1. 用户注册时须填写真实有效用户名、本人常用邮箱，邮箱用于接收注册验证码、器材逾期提醒、系统通知等重要信息，填写虚假邮箱导致无法接收通知、账号异常，责任由用户自行承担。
2. 用户账号、登录密码为个人专属凭证，严禁转借、出租、共享给他人。因主动泄露密码、转借账号产生的器材丢失、损坏、逾期扣费、违规记录等全部后果，由账号注册人承担全部责任。
3. 用户需妥善保管账号密码，若发现账号异常登录、被盗用，应第一时间联系器材管理员冻结账号并修改密码；未及时报备造成的损失不予免责。
4. 注册信息一经提交，不得恶意重复注册多账号，同一邮箱仅支持绑定一个有效用户账号。
三、器材借用权利与义务
1. 用户可在系统内查询可借用器材库存、预约借用时段，仅能预约本人使用范围内的教学、活动器材，不得代他人批量预约、囤积器材。
2. 预约成功后，须在预约时段内前往器材管理处现场核验身份、领取器材；逾期未领取且未提前取消预约，系统将记录一次违规，累计多次违规将限制预约权限。
3. 领取器材时应当场检查器材外观、配件、功能是否完好，若存在破损、缺失需当场向管理员报备并拍照留存，签字确认；领取后视为器材完好交付，归还时出现领取前已存在以外的损坏，由借用人承担维修 / 赔偿费用。
4. 借用器材仅限校内教学、社团、文体活动合法使用，严禁用于校外盈利、私人娱乐、违规活动、危险操作，一经发现管理员有权立即收回器材并永久封禁账号。
四、器材归还相关约定
1. 用户须严格按照系统预约的归还日期归还器材，如需延长借用期限，须在到期前通过系统提交续借申请，经管理员审核通过后方可延期；未申请续借逾期归还，系统自动生成逾期记录，按学校器材管理规定收取逾期管理费。
2. 归还器材时需保证器材完整、配件齐全、清洁无污渍，人为磕碰、摔损、进水、零件丢失、外壳开裂等人为损坏，借用人需按器材采购原价赔偿或自费更换原厂配件；丢失器材需全额赔付。
3. 归还前自行清理器材表面污渍、收纳整齐，未清理管理员有权拒收，视作未完成归还持续计算逾期时间。
五、用户行为禁止条款
用户不得实施以下行为，违反将视情节限制预约、封禁账号、通报所在班级 / 部门、要求全额赔偿：
1. 恶意重复预约、预约后无故弃领、频繁逾期归还；
2. 私自拆卸、改装、涂改、损坏器材机身、标识、配件；
3. 将借用器材转借校外人员、私自带出校园；
4. 利用系统发布虚假报备、恶意反馈、辱骂管理员等违规信息；
5. 破解、篡改系统数据、广告、预约记录、他人账号信息；
6. 利用系统漏洞囤积器材、虚假申领器材。
六、隐私与信息说明
1. 系统仅收集注册必填用户名、邮箱、预约记录、借还记录，所有数据仅用于校内器材管理，不会向第三方泄露、出售用户个人信息。
2. 系统发送邮箱验证码、逾期提醒、通知邮件仅用于服务必要场景，不会发送无关广告垃圾邮件。
3. 管理员仅可查看对应器材管理所需用户数据，严格保护师生个人信息，严禁私自导出、外传用户资料。
七、免责说明
1. 因用户自身保管不当、违规使用造成器材损坏丢失，管理方不承担任何赔偿责任。
2. 因停电、服务器维护、网络故障导致系统短暂无法登录、预约失败，管理方不承担延误责任，用户可线下联系管理员人工办理借还。
3. 不可抗力（自然灾害、设备大规模故障）导致器材损坏，经校方核实后可减免部分赔偿。
八、协议修订与生效
1. 学校有权根据管理需求更新本协议、使用规范，更新后系统弹窗提示，继续使用系统即视为接受新版条款。
2. 本协议自用户完成注册、勾选同意并点击注册按钮之日起永久生效；注销账号后协议终止，但此前产生的借还赔偿、违规记录仍然有效。
